# 电销列表页规则

## 页面骨架

基准画板固定为 `1366px × 768px`。页面由固定 Header、`200px` 侧栏和右侧内容区组成。右侧从上到下只有：系统内页签、筛选区、表格内容区；禁止生成独立操作栏。

- 内容区白色承载面统一圆角 `8px`。
- 内页签、筛选区、表格内容区之间垂直间距 `12px`。
- 正常数据页固定使用 `200px 侧栏 + 28px 间隔 + 1118px 内容区 + 20px 右边距`；该几何已由电销 Workspace Shell 回读确认。
- 垂直结构固定为 `56px Header + 712px Workspace`；Workspace 中 Content Shell 高 `668px`，Table Slot 高 `502px`。

## 系统内页签

- 结构与金毓盟的页签栏一致，但颜色使用电销主题。
- 使用真实 `Data Display / Tag / Tag` 实例；默认页签与当前页签分别配置未选中和主题选中状态。
- 当前选中页签文案必须等于当前侧边菜单 `sideActive`。
- 本阶段不处理横向溢出、更多菜单或复杂关闭后的重排。

## 筛选区

- 控件复用毓数已经映射的 Input、Select、DatePicker、DateRange 等真实实例。
- 控件固定宽度 `200px`、高度 `28px`；不随页面宽度拉伸。
- Filter Item 使用 Auto Layout `WRAP`：宽屏减少行数，窄屏增加行数。
- 筛选项由 HUG 标签 + 固定宽控件组成；父容器水平内边距 `20px`、垂直内边距 `16px`、横向间距 `32px`、纵向间距 `16px` 作为当前参考值，完整 Shell 验收时回读校正。
- 标签、输入值、占位、查询/重置/展开收起按钮文字统一 `12px`。
- 查询、重置、展开/收起组成不可拆分的操作组，跟随最后一个可见筛选项参与 WRAP。
- 筛选超过两行时才显示展开/收起；默认收起最多展示两行，展开后显示全部筛选项。

## 表格标题与操作

- 不存在独立的列表操作白色栏。所有列表操作必须放在表格白色承载面内、表格上方。
- 表格标题默认不显示；提示词明确要求标题时才显示，标题与操作按钮共享同一工具栏。
- 操作按钮默认左对齐；提示词明确要求右对齐时才可改为右对齐。左对齐使用全宽 Auto Layout `MIN`，右对齐使用 `MAX`，不得用 HUG 容器配合手工 x 坐标冒充对齐。
- 工具栏与表格共用表格内容区的水平内边距：距离白色承载面左右各 `20px`。在 `1118px` 内容面内，表格实际可视宽度为 `1078px`。
- 当标题隐藏时，操作按钮组从白色承载面左侧 `20px` 开始；当标题显示且操作仍为左对齐时，标题在前、操作组随后，间距由 Auto Layout 控制。
- 左侧按钮组距白色承载面顶部 `20px`；同组有多个按钮时严格按“主按钮 → 次按钮”排序，例如“新增 → 导出”，不得反排。
- 按钮文字统一 `12px`，Primary 使用 `电销/Light` 的主题色，不得出现毓数蓝或金毓盟蓝。

## 动态表格

拼装方法复用毓数的动态列契约：

```text
Text-V2 / Tag / Action Content-V2
→ Content Cell-V2.contentSlot
→ Row-V2.cellsSlot
→ Data Display / Table / Shell-V2.rowsSlot

Header Cell-V2
→ Data Display / Table / Shell-V2.headerSlot
```

- 表格使用 `Data Display / Table / Shell-V2` 的基础类型，列、行、状态、操作和分页按 PageSpec 动态组装。
- 表格本体位于白色表格内容区水平内边距内，距左右边缘各 `20px`；1366px 基准画板上的实际表格宽度为 `1078px`。
- 表头、数据、状态、行操作和分页文字统一 `12px`；设置 `headerFont=12px` 与 `contentFont=12px` 后必须回读确认。
- Action Content-V2 没有字号属性。完成操作项文案、数量和危险态设置后，对该实例内每个可见操作 TEXT 覆盖 `fontSize=12px`、`lineHeight=20px`，不得遗漏隐藏/显示切换后新出现的操作项；完成后遍历整表所有可见 TEXT 回读。
- Header Cell 数量 = `columns.length`；Row 数量 = `data.length`；每行 Content Cell 数量 = `columns.length`。
- 选择列只由 `tableSelection` 控制；显示时表头 Selection Cell 根背景绑定 `背景色/--qifu-bg-color-canvas`。
- Header 与所有数据行共用同一列宽数组；长文本省略、数字和操作列对齐、1–4 个行操作、状态 Tag 与横向溢出沿用毓数规则。
- 业务列使用内容感知列宽，禁止把所有业务列机械等宽。选择列固定 `40px`；操作列宽度为“操作列内容宽度 + 右侧 `20px`”，操作内容和表头均右对齐。
- 对每个业务列读取表头与所有可见数据单元格的内容宽度，取最大值作为 `intrinsicContentWidth`；该列基础宽度为 `leftPadding + intrinsicContentWidth`。状态 Tag 按 Tag 实例的可见宽度参与计算，不只读取内部文字宽度。
- 先从表格可视宽度中扣除选择列、操作列和所有业务列基础宽度，再将剩余宽度除以业务列数量，得到统一视觉尾部留白 `visualTrailingGap`。每列最终宽度为 `leftPadding + intrinsicContentWidth + visualTrailingGap`。
- `visualTrailingGap` 必须在所有业务列中保持一致，使“当前列最长可见内容右边缘 → 下一列左边缘”的视觉留白一致，而不是让单元格本身等宽。若剩余空间不足，则沿用毓数表格的长文本省略与横向溢出规则，不得挤压固定列或破坏右侧 `20px`。
- 写入完成后回读：表头与每行使用相同列宽数组；列宽总和等于表格可视宽度；各业务列实际视觉尾部留白差值不超过 `1px`。
- 1366px 的整体效果验证优先保留 `5–8` 个业务字段；正式业务明确要求更多列时按动态表格规则处理。

## 分页

- 复用 Pagination-V2，按 `total / pageSize` 计算页数。
- 分页放入与当前表格可视宽度相同的全宽 Auto Layout，容器内部使用 `primaryAxisAlignItems=MAX`，右内边距 `20px`。
- 共享 Table Shell 的内部分页 Slot 可能保留母版宽度 `1248px`。当电销表格可视宽度为 `1078px` 时，不得沿用 Slot 的 `MAX` 对齐；必须把分页 Slot 改为 `MIN`，让 `1078px` 分页容器从表格左边缘起排，再由容器内部右对齐，最终回读分页右边缘与表格右边缘间距为 `20px`。
- 上一页箭头向左，下一页箭头向右，页码从左到右递增且只有当前页选中。
- Pagination 控件顶部距最后一行数据底部 `12px`；按 `headerHeight + rowsHeight + 12px` 回读实际 y 坐标，不得沿用共享母版的空行高度制造大段留白。

## 状态与响应式

- 首轮只验证正常数据状态；Empty、Loading、Error 暂记 DEFERRED。
- 画板变化只改变每行容纳的筛选项数量、内容宽度和表格列宽；侧栏宽度、筛选控件宽度和字体大小不变。
- 不直接 resize 根画板后等待内部自动正确；必须回读内容面、筛选 WRAP、表格 Slot 和分页对齐。
- 当固定菜单总高度超过 `712px` Workspace 时，在 `全部菜单` 下建立 `Dianxiao Menu Scroll Viewport`；固定 `全部菜单`、分割线和 `收藏菜单`，仅滚动中间一级菜单树，并使 `sideActive` 可见。

## 完整页验收结论

- `1366px × 768px` 电销纠偏回归页已在 Figma Page `测试` 中完成结构回读和整页截图检查。
- 选中菜单与当前页签均为 `个人信息`；17 个一级图标均为 16px × 16px；筛选、按钮、表格和分页目标文字均为 12px。
- 电销品牌交互色全部解析到 `电销/Light`；选中个人信息 Icon 为主题色；旧的独立操作栏已删除；表格标题默认隐藏；左侧操作顺序为主按钮 → 次按钮，距表格白底左侧和顶部均为 20px；表格左右内缩 20px。
- 分页上一页向左、下一页向右；分页距最后一行数据底部 `12px`，距表格白底右侧 `20px`。
- 页面字体家族仅为 PingFang SC 与 MiSans；未发现意外字体。
- 当前 `readiness=ready`，可在用户指定 Page 中正式使用。
